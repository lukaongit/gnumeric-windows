# Gnumeric for Windows

Wanted to download gnumeric for windows, beacuse unlike libreoffice, onlyoffice and microsoft office gnumeric is faster and does not complicate, but it seems there was no version avalaible for windows, so i made one from official source code.
I know there is easy way to run it over WSL, but native is native, no matter how you turn it.

The interface language follows your Windows display language (English by default); you can override it with the `LANGUAGE` or `LC_ALL` environment variable.

**Portable** application: just clone/download this repository and run `bin/gnumeric.exe` – no installation required.

Based on Gnumeric **1.12.63-dev** (official upstream master source code).
